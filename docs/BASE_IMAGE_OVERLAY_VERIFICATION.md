# 基础图透明叠加验证

验证日期：2026-10-14。分支 `codex/base-image-overlay`；版本保持 1.14.3，匹配特征保持 v6，HTTP API 合约保持 2.0。本次没有发布 Release。

## 实现与接口

新增 `--overlay-strength` / `overlayStrength`，范围为有限数 `0..1`，默认 `0`，大于零直接开启。选图后以 BGR 加权混合：`素材 × (1 − 强度) + 基础图 × 强度`。参考为当前匹配流程经过缩放、upscale 和镜像补边的目标工作图，不能恢复之前缩小时丢失的原图细节。

普通、流式、分块和 DeepZoom 共用输出合成入口。全图像素中心坐标逐块双线性采样，跨块读取相邻像素，参考图外边界夹紧。素材缓存只读，需要调整时只复制一次；随机亮度调整先于叠加。关闭叠加时不保留额外参考图，不增加叠加采样和复制。缺失素材保持原失败计数和背景，分析报告注明分数描述选图质量。

## 功能验收

- CUDA 与 CPU-only 构建、各自完整 CTest 和 `mosaicraft_webui_smoke` 均通过；缩放/upscale/补边回归使用 180×320 特征，实际执行 CUDA 匹配并分别检查开启前后选图不变。
- 覆盖强度 `0、0.25、1` 的结果、全图坐标跨块插值、外边界夹紧、非连续参考图、下采样和缺失参考图报错。
- 同一素材在不同位置独立混合，缓存和素材文件不被修改；同时启用亮度调整时执行顺序正确。无损 batch/stream 输出像素完全一致。
- 验证独立小图与 DeepZoom；JPEG 对照使用相同的有损编码步骤，避免把色度采样误差当成叠加误差。
- CLI、API 和 Web UI 拒绝越界值及 NaN/Infinity；同步与异步 API 均能生成可解码图片，端点发现包含新字段。Web UI 的默认值、步长、命令生成和请求构造通过检查。

## 实际样图与性能

从现有 45,625 张、180×320 特征的图库创建独立 SQLite 快照，并把特征文件硬链接到私有目录，ANN/特征缓存仅写入私有目录；素材只读。使用 `test_input_photos/target5.png`、CUDA 匹配、`topNrandom=1`、关闭随机亮度和分析、PNG stream。每个场景预热一次后测三次，轮换场景顺序，取中位数；共 24 次运行。基线由提交 `5d96431` 构建。

完整运行数据、输入和二进制摘要见 [JSON 记录](performance/base-image-overlay.json)。峰值内存为 Windows PeakWorkingSetSize，每 25 ms 采样，不含显存。私有特征目录未复用原图库的 FeaturePack，来源读取和 PNG 编码占较大比例；下列耗时用于同条件对照，不表示其他图库或输出格式的性能。

| 场景 | 工作图 / 输出尺寸 | 墙钟中位数 | 进程峰值中位数 |
|---|---|---:|---:|
| 原版本 | 360×640 / 7200×12800 | 13.375 s | 342.82 MiB |
| 新版本，强度 0 | 同上 | 13.603 s | 342.75 MiB |
| 强度 0.1 | 同上 | 13.149 s | 342.86 MiB |
| 强度 0.2 | 同上 | 13.372 s | 342.89 MiB |
| 强度 0.3 | 同上 | 13.138 s | 343.16 MiB |
| 强度 0.2，小样本 | 180×320 / 3600×6400 | 9.517 s | 292.25 MiB |

关闭叠加的输出在所有运行中与原版本 SHA-256 完全相同，墙钟中位数相差 +1.70%。开启后的总耗时差异不据此解释为加速；采样和混合处于已有贴图/编码流水线中，强度 0.2 的工作线程采样耗时之和为 760.8 ms，混合为 43.7 ms，不能直接加到墙钟耗时上。

两个输出场景的像素面积相差四倍，叠加工作线程缓冲预算均为 **2,787,840 字节（约 2.66 MiB）**，包括最多 8 份素材副本、参考小块和水平插值表。参考工作图分别为 172,800 和 691,200 字节；没有额外分配约 65.92 / 263.67 MiB 的完整输出参考图。此预算不是进程总内存上限，既有图库记录、图片缓存和两行输出缓冲仍占用内存。

实际输出与独立的整图缩放/加权混合对照最大相差 1 个通道量化值。相对基础图的 BGR 平均绝对误差从强度 0 的 31.56，降至 0.1 的 28.41、0.2 的 25.25、0.3 的 22.09；该指标反映混合比例，不是感知质量评分。视觉检查中整体色调和明暗逐步接近基础图，局部素材对比随强度增加而减弱；当前样本没有观察到额外插值接缝，默认仍保持关闭。

对照图、原始输出、完整日志和私有验证脚本位于忽略目录 `build/overlay-validation`。原图库数据库验证前后 SHA-256 一致。

## 复现采样

先准备指向私有特征目录的数据库快照，然后复用已有显式基准脚本；该选项只影响 current 二进制，baseline 始终关闭叠加：

```powershell
python scripts/benchmark.py --exe build/Release/bin/mosaicraft.exe --snapshot build/overlay-validation/snapshot.db --target test_input_photos/target5.png --output-dir build/overlay-recheck --format png --write-mode stream --out-w 360 --out-h 640 --analysis-mode off --runs 3 --overlay-strength 0.2
```

该脚本使用原有的显存采样和进程峰值采样方式，与本次 25 ms 私有采样脚本的测量开销不同，结果应单独报告。不会自动加入默认构建或 CTest。
