# Web UI 使用指南

> 本指南对应当前源码。已安装版本的可用参数以程序 --help-all 和包内 `BUILD_INFO.txt` 为准；源码开发能力不等于稳定包已发布。

## 建库到生成

解压后，Windows 双击 `MosaicraftWebUI.exe`，Linux/macOS 在解压目录运行 `./MosaicraftWebUI`。浏览器默认打开 [http://localhost:8080](http://localhost:8080)。

1. **建库。** 在「建库」页填写素材目录和图库输出目录，点击「运行」。完成后点击「使用此图库」，将数据库路径填入生成表单。
2. **设置输出。** 在「生成马赛克」页填写目标图和输出路径。用「输出规划」查看尺寸、内存和文件体积估算，展开「目标与图库覆盖」检查亮度候选不足的区域。初次试跑可将「输出 Tile 尺寸」设为 `18x32`。
3. **预览与选图（可选）。** 在「预览」页查看目标参考图、素材复用和匹配误差，或手动替换单格素材。可保存 A/B 快照比较参数。保持当前预览开启并完成匹配，正式生成会沿用选图结果。
4. **生成。** 点击「运行」，在「任务与结果」查看文件、阶段耗时和历史摘要。生成前勾选「质量分析」可查看误差直方图和热力图，勾选「资源监控」可查看进程 CPU、内存及可用的 CUDA 指标。

相对路径以页面顶部显示的服务工作目录为准。更多参数和示例见「使用帮助」。

命令区可选择 Windows PowerShell 5.1、PowerShell 7.3+、CMD、Bash、Zsh 或 POSIX sh，默认按浏览器平台选择并记住设置。程序未加入 PATH 时可填写绝对路径，或 Windows 的 `.\mosaicraft.exe`、Linux/macOS 的 `./mosaicraft`。复制命令使用所选 Shell 的引用规则；页面「运行」继续通过本地服务执行，不受 Shell 选择影响。CMD 遇到 `%`、`!` 或内嵌双引号，PowerShell 5.1 遇到空参数或内嵌双引号时会提示切换 Shell，避免复制后参数被改变。
## 实际后端与设备

表单中的 backend、device 和评分模式是请求设置；任务实际使用的计算路径在执行后才能确认。任务排队或尚未完成预检时，页面显示待确认状态。运行后在任务详情、事件和预览状态查看实际后端、设备及评分模式。

compatible 模式下 Vulkan/Metal 使用 GPU 特征统计与 CPU FP64 评分，两个阶段显示不同计算路径属于正常执行。auto 在准备阶段可能回退到 CPU；应以任务实际状态及原因判断，不能只看表单选项。切换后端、设备或评分模式后应重新计算预览，新的运行身份参与缓存复用校验。

## 复制命令

| 目标终端 | 页面选项 | 提示 |
| --- | --- | --- |
| Windows 自带终端环境 | Windows PowerShell 5.1 | 使用 PowerShell 5.1 的参数引用规则。 |
| 已安装新版 PowerShell | PowerShell 7.3+ | 使用 PowerShell 7.3+ 的参数传递规则。 |
| Windows 命令提示符 | CMD | 特殊字符限制会显示警告。 |
| Linux / macOS Bash | Bash | 不需要安装 PowerShell。 |
| macOS 常用终端 | Zsh | 不需要安装 PowerShell。 |
| POSIX Shell | POSIX sh | 适用于支持 POSIX sh 的终端。 |

Shell 只决定复制出来的命令文本。点击页面「运行」仍由本地服务处理。跨操作系统复制时，请同时检查可执行文件路径和数据路径；Shell 引用转换不会转换文件系统路径。

## 便携工程

「便携工程」页支持工程信息、完整性检查、回导和 ZIP 打包。HTML 输出必须下载完整 ZIP，单独保存 index.html 无法携带素材。见[便携工程与回导](portable-projects.md)。

## 路径和诊断

相对路径以服务工作目录为基准。任务失败时保留任务诊断并查看设备不可用、资源预算和输出覆盖提示；监控数据无法获取时显示不可用，不等于利用率或显存为零。

接口集成、任务事件与预览状态字段见 [HTTP API](../reference/api.md)，后端行为见[GPU 后端](gpu-backends.md)。
