# 全库颜色排序验证

验证日期：2026-10-12。当前为未发布更新，特征版本仍为 v6。

## 排序定义

实际图库图片以统一 CPU 算法缩小到 32×32。HSV 色相划分 36 个色箱，合并相邻色箱后选择占比最大的色系，并用饱和度加权的圆周均值确定主色相。饱和度低于 32 或明度低于 16 的像素参与中性色计数；中性色占比不低于最大彩色色系时，归入灰度区。

灰度区按平均 LAB 亮度从黑到白。彩色区每 15° 划分一个色相区间，按红到紫排列，首区由亮到暗，相邻区间交替明暗方向，再按精细色相和彩度排序；相同键按内容哈希和图片 ID 排列。颜色键独立缓存，不改马赛克匹配特征。

## 验证范围

- CPU-only 和 CUDA Release 均通过 CTest：49 个核心用例、14 个服务回归用例；两套 Web UI/API smoke 均通过。
- 回归覆盖主色与平均色不同、黑白灰和彩色顺序、同目录和递归建库、中文路径、混合扩展名、追加、重复及空目录追加、仅归一化和重排后生成。
- 300 张合成图片分别用 CPU/CUDA 建库，追加 12 张后，两种后端的内容哈希到文件名、颜色键映射完全一致，最终编号为 `000000` 至 `000311`。
- 比较追加前后旧图片的 SHA256、ID、使用次数和独立特征路径，全部保持一致。两套程序均成功生成 1800×3200 PNG。
- 少量故障用例覆盖未索引文件冲突、Windows 文件占用、暂存/发布/恢复阶段中断、数据库已提交但清单未清理、相对路径恢复和 Windows 路径大小写。
- 在真实 CUDA 建库进程发布新文件名时强制终止，数据库命令拒绝读取未恢复图库；再次追加建库恢复并完成 300 张图片的连续编号，SQLite 完整性检查通过。
- 独立 CLI 进程在建库持锁期间读取同一图库被拒绝；C 盘已索引图片向 D 盘重排在移动前失败，原记录路径和图片均保留。

## 单次样本耗时

使用 300 张 72×128 合成源图，归一化到 180×320，4 个归一化线程；追加样本为 12 张。以下是单次测量，颜色阶段包括缓存读取、统计、路径检查、排序、文件重命名和数据库提交。

| 场景 | 补算颜色 | 重命名图片 | CPU 颜色阶段 | CUDA 颜色阶段 |
|---|---:|---:|---:|---:|
| 首次建库 | 300 | 300 | 0.660 s | 0.704 s |
| 追加 12 张 | 12 | 307 | 0.640 s | 0.656 s |
| 重复追加相同图片 | 0 | 0 | 0.088 s | — |

颜色统计使用同一 CPU 算法，表中后端名称指建库特征提取后端。此样本验证功能和增量缓存行为，不能据此推算数万张真实图库的耗时；大量追加可能需要重命名多数旧图片。

上述故障验收使用临时合成图库。未索引的目标冲突文件保留并报错；旧图片跨卷重排不属于支持范围。文件系统恢复依赖清单和数据库提交标记，未完成恢复时拒绝生成与维护。

## 现有图库重新建库

2026-10-12 对现有 `library/180x320` 图库执行了同目录追加建库。操作前确认 45,625 张已索引图片全部存在，没有未索引图片占用目标路径；保存数据库快照、原路径和全部图片及独立特征文件的 SHA256。图库特征均为 v6，因此本次没有重新提取匹配特征。

| 场景 | 新增图片 | 补算颜色 | 重命名图片 | 颜色阶段 | 命令总耗时 |
|---|---:|---:|---:|---:|---:|
| 现有图库首次颜色重排 | 0 | 45,625 | 45,624 | 333.840 s | 421.519 s |
| 空输入目录追加检查 | 0 | 0 | 0 | 28.083 s | 38.355 s |

颜色阶段包括全库路径检查、统计、排序和重命名；空目录追加仍检查全库，但复用已保存的颜色信息。这两次为同一台 Windows 机器的单次测量。

- 最终图片数量保持 45,625，数字编号连续为 `000000` 至 `045624`，扩展名保持原样。文件名顺序与 `(颜色键, 内容哈希, 图片 ID)` 排序逐条一致。
- 全部图片的 SHA256、ID、元数据、匹配特征及其文件字节、独立特征路径和使用统计保持一致。9,881 条 `usage_stats` 和已有 `target_runs` 记录未改变。
- 颜色缓存全部为当前算法版本，内容哈希与图片记录一致；独立抽样重新计算 273 张实际图片的颜色键，全部匹配。SQLite 完整性检查为 `ok`，没有遗留恢复清单或暂存目录。
- 26,168 张主色为低饱和度或黑白灰的图片进入中性区，编号为 `000000` 至 `026167`；其余 19,457 张进入彩色色相区。实际缩略图抽样可见色系和明暗过渡，多色图片按主色归类；各色系数量不均匀，因此不保证无跳跃渐变。
- 空目录追加后，全部路径和颜色顺序保持一致；无需补算颜色或改名。
- 重排后使用数据库副本执行 CUDA 马赛克生成，得到有效 90×160 PNG，完成 100/100 块，图片加载失败为 0，grid/tiny/edge/lbp 均参与匹配；生成测试没有修改现有图库的使用统计。
