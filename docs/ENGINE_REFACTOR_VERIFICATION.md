# 构建入口与引擎整理验收

2026-11-09，本轮以 `404569e` 为重构前基线，固定同一台 Windows x64 主机、MSVC 19.51、OpenCV 4.12.0 和 CUDA 13.5.37。实机为 RTX 4060 Laptop（sm_89），CUDA Driver/Runtime API 版本均为 13050。

## 变更边界

- 构建命令只在 [README：安装与构建](../README.md#安装与构建)维护完整说明；日常 Windows/Linux CI 使用相同平台 Preset、显式构建目标和 CTest 入口。
- 分析报告只借用图像、特征和标量数据；返回待提交计数，由引擎按原条件更新 `usage_stats` 与 `target_runs`。`images.use_count` 是独立字段，不等同于这些使用统计。
- 基准统计集中持有，打印移至独立模块；字段文本和顺序保持一致，时钟读取位置与启用条件保留。
- 邻域惩罚与窗口更新共用任务级状态；保留逐项浮点加法、两个后端原有排序和平分规则、随机数调用及空候选行为。候选评分中仅查询已有容器和缓存，不增加逐候选堆分配。
- 未修改 CLI/API、特征 v6、图库格式、CUDA 内核、资源预算或发布版本。

## 重构前后对照

保存基线程序，生成 24 张合成素材，分别建立 180×320 和 72×128 图库。每次运行恢复同一数据库快照；固定 Top-N 为 1、关闭随机亮度调整、启用自适应权重与 0.25 基础图叠加，邻域窗口为 7，输出 PNG。

两种尺寸 × CPU/CUDA × 分析关闭/开启，共八组：选图索引、输出文件与像素、分析目录文件名及内容、`images.use_count`、`usage_stats` 和 `target_runs` 的非时间字段均精确一致。时间戳与耗时不参与内容一致性比较。

最初使用渐变目标时，旧程序自身 A/A 重复运行即出现模板 CUDA 报告末位浮点波动；该路径使用浮点原子归约。本轮改用每个 9×16 小块颜色固定的 90×160 目标，先确认旧程序 A/A 精确一致，再执行上述精确对照；没有放宽比较精度或修改内核。补边及复杂图像行为由既有回归覆盖，不据此承诺任意模板输入的报告逐字节确定性。

本机基线、请求、清单与日志保留在被 Git 忽略的 `build/refactor-audit/`，不加入产品包。本轮未推送或触发远端工作流；Linux 和 macOS 原生构建尚未在本轮实测，继续由既有 CI/原生打包流程验收。
