# HTML 工程单份素材与原文件名验收

> 本文保留实施过程中的历史验收数据。当前工程已取消格式版本及旧总览/缩略图兼容逻辑，现行契约见 `CLI_PROJECTS.md`。

日期：2026-11-12。软件仍为 1.15.4，API 1.4；新工程格式为 2，兼容读取格式 1。没有推送、打标签或发布 Release。

## 实现边界

- 不生成 overview、素材缩略图、目标缩略图或兼容显示副本。
- 每份唯一素材按文件字节 SHA-256 去重，只复制一次；保留图库文件名、大小写、扩展名和全部文件字节。
- 每份素材位于 `assets/<素材索引>/<原文件名>`，不同内容同名时仍独立保存，相同字节多个来源名采用最终排列首次使用的名称。
- 浏览器与原生回导共用这份素材。目标参考与叠加共用无损 `target.png`。
- HTML 缓存没有应用大小上限，也没有因格子数或内存预算触发的总览回退；保留 8 路加载并发和视口大小画布。系统及浏览器本身仍有资源限制。
- 加载完成时只更新该素材对应的可见格；格子共享物理像素边界，避免缩小时露出背景及增量绘制的顺序差异。
- 实时 Web UI 预览的原有缓存策略不变。浏览器不支持的图片格式报告加载失败，不生成第二份转换图片。
