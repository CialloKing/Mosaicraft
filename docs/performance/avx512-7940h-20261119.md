# CPU AVX-512 复测：Ryzen 9 7940H

2026-11-19，Windows 10 x64（19045）、Ryzen 9 7940H（8 核 16 线程）、平衡电源方案。对同一个 `4a7662255` Windows CPU Release CLI 分别强制 AVX2 和 AVX-512，核对报告中的实际评分内核。**本次结果不支持改动 `auto`；保留 AVX2。**

## 完整 `create`

使用 45,613 张素材的私有快照和已持久化的索引。每次计时前从只读快照恢复私有工作数据库，不写真实图库。固定 `target3.jpg`、种子 42、Top-10、匹配与输出格 9×16、PNG 输出；测进程启动至写完输出退出的墙钟，不开详细诊断，不计数据库恢复和输出校验。

| 格数 × 候选 / 线程 | 样本 | AVX2 → AVX-512 墙钟中位数（秒） | AVX-512 / AVX2 配对比中位数 | 配对比 95% 区间 | AVX-512 更快的对数 |
|---|---:|---:|---:|---:|---:|
| 57,600 × 150 / 自动 | 1 次预热、3 对 | 8.314 → 8.179 | 0.9838（快 1.62%） | 仅初筛 | 2/3 |
| 14,400 × 600 / 16 | 2 次预热、8 对 | 4.536 → 4.514 | 1.0170（慢 1.70%） | 0.9657–1.0492 | 2/8 |
| 900 × 150 / 16 | 2 次预热、8 对 | 1.570 → 1.557 | 0.9881（快 1.19%） | 0.9655–1.0013 | 6/8 |

配对比是每轮用 AVX-512 墙钟除以同轮 AVX2 墙钟，再取中位数，不是比较两列各自的中位数；14,400 格的两种聚合方向不同，以配对结果判定。8 对样本的区间用配对比自助法估计，均跨过 1。57,600 格未过 3% 初筛线，未进入 8 对主场景验收。14,400 格单独复测了[上一次的场景](create-182a41ebb.md#正式配对同一窗口)，900 格用于小图对照；两者均未证实端到端提速。

## 正确性与分派

- 三种规模的每次计时输出均与各自的 AVX2 PNG 字节相同。另用 `mosaicraft_match_benchmark --seed 42 --selections --summary` 回放，两种内核的选图索引逐格相同，回放 PNG 也与计时 PNG 相同。
- 主场景的一次详细回放中，批量基础评分计数为 **346.3 → 348.6 ms**。这只是该评分段的单次测量，不用于端到端验收，也不能据此判定内核本身有回退。
- 900 格实测，未屏蔽及通过 `OPENCV_CPU_DISABLE=AVX512-SKX` 屏蔽后，`auto` 都选择 AVX2，PNG 相同。屏蔽后强制 AVX-512 明确报错、退出码为 1，未生成 PNG。这是同机模拟，不是 AVX2-only 真机测试。

## 复现

从仓库根目录运行；`$prepared` 指向已准备好索引和 `report.json` 的私有基准。两种内核只通过基准进程的环境变量强制。本次只测了上述 CPU、Windows 构建和固定输入，未改生产代码、未发版。

```powershell
$exe = 'build/windows-cpu/Release/bin/mosaicraft.exe'
$prepared = 'build/backend-retest-20261118/runs'
$trial = @('--baseline', $exe, '--candidate', $exe, '--backend', 'cpu', '--prepared', $prepared,
    '--input', 'test_input_photos/target3.jpg', '--baseline-setting', 'kernel=avx2',
    '--candidate-setting', 'kernel=avx512')
python scripts/benchmark_create.py @trial --tiles 57600 --threads 0 --warmups 1 --rounds 3 --output build/replay-isa-main
python scripts/benchmark_create.py @trial --tiles 14400 900 --threads 16 --warmups 2 --rounds 8 --output build/replay-isa-controls
```

[机器可读记录](avx512-7940h-20261119.json)包含各次样本的运行顺序、墙钟、实际内核、输出和基准输入指纹。
