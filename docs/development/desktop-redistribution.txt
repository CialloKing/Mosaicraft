Mosaicraft Desktop (CPU)
======================

Extract the complete archive and keep the package layout intact.
Windows: open bin/MosaicraftDesktop.exe.
Linux: run ./bin/MosaicraftDesktop from a desktop session (X11/XWayland or Wayland).
macOS: open MosaicraftDesktop.app. The bundle is ad-hoc signed, not notarized.
No system Qt installation is required. This archive does not supply a display
server, graphics drivers, or a replacement for the host operating system libraries.
