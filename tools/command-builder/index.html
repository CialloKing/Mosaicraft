使用帮助

从第一次建库到找到生成结果，在这里了解每一步怎么做、每个选项会影响什么。帮助内容随页面提供，离线也能阅读。

快速开始 路径与图库 尺寸与格式 匹配与权重 开关与预览 建库选项 查询与管理 任务与结果 常见问题

第一次使用：建库 → 生成 → 查看结果

  1. 准备素材图库。在“建库”页填写素材所在的图片目录和图库输出目录，点击“运行”。生成会从这些素材中挑选图片，拼成你的目标图片。
  2. 复用建好的图库。等建库任务完成，在下方结果区点击“使用此图库”，数据库路径会自动填入生成和查询页面。
  3. 提交生成任务。在“生成马赛克”页填写目标图片和主图输出路径，打开“预览”页并点击“开启预览”。用“手动选图”点击格子，可从推荐候选或整个图库替换。返回生成页运行时会沿用预览排列。
  4. 到“任务与结果”查看。点击任务可查看阶段、警告和结果。完成后复制实际路径或下载主图；已生成的预览图会直接显示在页面中。

通过 MosaicraftWebUI.exe（Linux/macOS 为 ./MosaicraftWebUI）启动后可直接运行。单独打开 HTML 时，可以阅读帮助和复制命令，再到程序所在目录的终端执行。

路径怎么填，图库是什么

目标图片是你希望拼出来的整体画面；素材图库是组成这幅画面的许多小图片。建库会准备统一尺寸的素材、数据库和特征文件。

输入或粘贴服务器所在电脑上的路径，例如 D:\photos\target.jpg 或 /home/me/photos/target.jpg。页面上方显示服务工作目录，相对路径从那里开始解析。“复制为路径”附带的外层双引号会自动去掉，中文和空格可以保留。

数据库可填写 mosaicraft.db 文件，或包含它的图库目录。首次建库时将素材输入目录与图库输出目录分开填写，后续移动图库时一起保留图片、数据库和特征文件。

生成的输出路径填写到文件名，例如 D:\results\mosaic.png。选择明确的输出格式后，程序会调整扩展名；结果区会显示最终保存的位置。

浏览器会保存表单草稿和按用途分类的最近 10 个路径，刷新会恢复上次的选择。“清空最近路径”只清空候选记录。

生成选项速查

选项后面的 -i、--preview 等名称对应命令行参数。网页会根据同一份表单生成命令和提交请求，初次使用可以保留默认匹配参数。

尺寸与格式：小块有多少，最终图片有多大
选项作用与使用方式
Tile 宽度 / 高度
--tile-w / --tile-h		把目标图片按多大的区域划成一个匹配小块，默认 9 × 16。数值越小，小块通常越多，处理量和输出尺寸也会增加。
输出 Tile 尺寸
--output-tile		每张入选素材在最终主图中占用的像素尺寸，格式为 宽x高。调小可减少主图体积；默认 180x320，横向图库会自动调整默认方向。
输出宽度 / 高度
--out-w / --out-h		设置切块前目标图的缩放尺寸。留空或 0 为自动；只填写一轴时另一轴按原比例推导，同时填写两轴时按指定尺寸缩放。最终主图还取决于小块数量与输出 Tile 尺寸。
上采样
--upscale		将目标图先放大再切块。2 倍上采样通常带来约 4 倍的小块数量，也会增加耗时。留空使用默认值，先从 1 倍开始。
输出格式
--format		优先级为：显式选择格式 → 指定输出文件后缀 → 输入文件后缀 → PNG。无后缀输出会追加实际格式；留空保存为 ./output/output.实际后缀。支持 JPG/JPEG、PNG、WebP、TIFF/TIF，忽略大小写。输入后缀无法推导时回退 PNG；不支持的输出后缀需要修改或显式选择格式。
超限适配JPG 单轴上限为 65,500，WebP 为 16,383。自动推导时超限改存 PNG，保留完整尺寸；显式选择 JPG/WebP 时缩小每块输出 Tile，整数取整可能略微改变比例。网格某一轴的块数本身已超限时无法缩小到合法单图，需要 PNG/TIFF 或分块输出。分块和 DeepZoom 沿用分片规则。
JPEG/WebP 质量
--quality		范围 1～100，数值越高通常越清晰、文件越大；不控制 PNG、TIFF 或结果预览的质量。
PNG 压缩级别
--png-level		范围 1～9。较高通常更省空间、编码更慢，不改变 PNG 的像素内容。默认 1 优先保存速度。自动改存 PNG 后也使用此设置，JPEG/WebP 质量不控制 PNG。
写入模式
--write-mode		auto 自动选择；stream 按行分段写入以降低整图内存占用；batch 在内存中完成整图再保存。WebP 使用整图编码。

例如目标图为 90 × 160，匹配 Tile 为 9 × 16，会得到 10 × 10 个小块。输出 Tile 为 180 × 320 时，主图是 1800 × 3200；改为 18 × 32 时，主图为 180 × 320。

输入 target.jpg、输出 result.webp 且保持自动时，优先使用 WebP，超限改存 result.png。若输出为 result.png，但显式选择 JPG，则保存为 result.jpg，超限时缩小 Tile。任务中的“输出计划”解释适配过程，“实际结果”提供已保存文件。

匹配与权重：选哪些图片，怎样减少重复
选项作用与使用方式
候选数
--candidates		每个小块先检索多少张素材供精细比较，默认 150。增大可扩大选择范围，也会增加计算量；效果还受图库内容影响。
TopN 随机
--topn-random		从评分靠前的 N 个候选中随机选一张，默认 10。设为 1 时选最优候选，较大的值增加变化和多样性，也可能降低局部贴合程度。
L 亮度范围
--l-range		允许的目标小块与候选素材亮度差，默认 20，范围 0～255。调大可接纳更多明暗不同的素材；调得过小可能使某些小块没有候选。
邻域窗口
--neighbor-window		检查本次选图中最近一段选择，减少附近反复使用同一素材。0 使用自动窗口；具体抑制效果还受图库和评分影响。
邻域惩罚
--neighbor-penalty		提高窗口内重复素材的评分成本，默认 100；数值越大越倾向换用其他候选。它与其他去重规则共同生效。
复用惩罚
--penalty		按图库记录的素材使用计数增加评分成本，默认 0.01，与本次任务的邻域惩罚分开计算。
LAB 权重
--lab-weight		整张素材与目标小块的平均颜色、亮度相似程度。
Grid 权重
--grid-weight		不同位置的颜色布局，例如上方偏亮、下方偏暗的分布。
Tiny 权重
--tiny-weight		缩略图中的整体明暗结构。
Edge 权重
--edge-weight		边缘密度，例如平滑区域和轮廓较多的区域。
LBP 权重
--lbp-weight		局部纹理，例如细碎纹理与较平坦的表面。

特征权重决定各项相似度的相对重要程度，必须非负且总和大于 0。初次使用先保留默认值，随后一次调整一项，结合主图与分析报告观察效果。

开关与预览：勾选后会发生什么

实时预览支持拖动和缩放，按需加载窗口内的图库图片。勾选“生成结果预览”则会在正式生成时额外保存 JPEG。

选项勾选后的行为
生成结果预览
--preview		生成结果预览默认关闭。勾选后在主图旁额外保存 主图名_preview.jpg，供页面快速查看。预览保持比例、不放大，宽度最多 1400 像素、总像素最多 400 万；主图仍按原设置保存。分块和 DeepZoom 模式不能同时生成单图预览。
质量分析
--analyze		生成匹配评分、素材频次、热力图和 HTML 等分析文件，方便检查效果；增加分析与写文件的耗时。使用统计在分析流程到达提交点时写入。
性能分析
--benchmark		采集和显示处理阶段耗时及缓冲统计，便于判断时间花在哪里。并行阶段的时间可能重叠，不能直接相加。
自适应权重
--adaptive-weights		根据目标小块的平滑、边缘、纹理等特征调整匹配权重，可能改变选图结果。
随机亮度调整
--color-adjust		选图后随机改变每个小块的亮度，默认关闭。“亮度扰动幅度”控制变化范围，例如 0.04 对应最多约 ±4%；只填幅度不会启用该功能。
基础图叠加强度
--overlay-strength		将处理后的目标图叠加到素材上，0 关闭，范围 0～1。0.2 表示 80% 素材与 20% 目标图；增大可增强整体目标画面，也会弱化素材本身的细节。
仅 CPU
--cpu		强制使用 CPU。未勾选时会尝试可用的 CUDA 后端；CUDA 不可用或准备资源不足时，允许回退的阶段会显示警告与实际使用后端。
分块输出
--tiled		将结果分别保存为许多 JPEG 小块，输出前缀后会生成 _files 目录。结果区提供实际目录路径，可在服务器电脑上打开该目录。
DeepZoom
--deepzoom		生成分层小块、.dzi 清单和 HTML 查看页，供缩放浏览。需要一起保留相关文件与目录；查看页依赖的浏览组件需要联网加载。

建库选项

选项作用与使用方式
图片目录 / 输出目录 / 数据库分别填写素材来源、准备后的图库目录和数据库位置。数据库留空时自动在输出目录内生成，输出目录留空使用 library。
归一化尺寸
--normalize-size		建库素材统一处理到的尺寸，默认 180x320，宽高各支持 1～8192。同一已有图库须保持尺寸一致，改变尺寸请使用新的输出目录和数据库。
线程数
-t		CPU 图片处理使用的线程数量，留空或 0 自动选择。线程更多不保证一定更快，也会增加同时处理图片的资源占用。
增量模式
--append		向现有图库加入新素材并刷新需要更新的特征；结束后仍会按颜色排列整个图库，旧数字文件名可能改变。
递归扫描子目录
-r		同时查找图片目录的下级文件夹，默认只扫描指定目录这一层。
仅归一化
--normalize-only		只准备统一尺寸的素材，不完成用于匹配的特征提取，也不进行全库颜色重编号。要用于生成马赛克，还需正常建库。
跳过已有图库确认
-y		允许在已有记录的图库继续普通建库；选择增量模式时也可继续建库。普通和增量建库都会按颜色重新编号；输入与输出目录相同时，已索引原图的文件名也可能改变。

查询、统计、健康、清理和使用记录

功能什么时候用
查询填写图片路径，查看图像信息，以及指定图库中亮度接近的候选数量和亮度分布。
统计查看图库图片数量、尺寸和特征等汇总，确认当前使用的是哪个图库。
健康检查素材文件是否缺失、特征状态等，排查图库读取或生成问题。
清理清理素材文件已丢失的悬空记录及关联特征文件。未勾选“跳过确认”时只预览；勾选后运行还会要求确认实际操作。
使用记录 / Top N查看已记录的素材使用情况，Top N 控制显示多少条。该统计由质量分析流程写入，普通生成不会补写。

任务进度、诊断与结果怎么读

排队表示等待执行，只有排队任务可取消；运行中显示当前阶段和已完成数量，计数是阶段进度。读取索引、单次编码等阶段可能只有阶段名称与运行时间。

警告可能表示 CUDA 回退、跳过素材或缺失小块，结合实际后端和最终状态判断结果。失败区会给出原因、相关路径及处理建议，技术详情可展开查看，也可复制或导出诊断 JSON。

主图保存后仍可能进行预览、分析和统计提交。后续阶段失败时，已经有效保存的主图仍显示在结果区。下载以登记的实际产物为准；文件已被改写或删除时会提示不可用。

切换功能页或阅读帮助时任务继续跟踪。“恢复参数”将选中任务的参数填回表单，检查后需要自行点击运行。HTML 报告以附件下载；分块结果显示实际目录或清单路径。

任务和诊断只保留在当前服务会话，保留最近 50 个完成任务。刷新页面可恢复同会话中的跟踪；重启服务会清空旧会话记录。清理任务记录只移除记录，输出文件仍然保留。

常见问题

为什么预览选项变灰了？

检查是否勾选了分块输出或 DeepZoom；这两种模式不支持单图预览，页面会清除并禁用“生成结果预览”。旧服务未提供预览能力时也会禁用，并显示原因。

为什么没有候选，或者部分小块是空的？

先检查图库是否可读、素材是否足够，以及 L 亮度范围是否过窄。适当放宽范围或补充对应明暗、色调的素材；缺失素材和特征可通过健康检查与重新建库排查。

为什么文件名后缀或最终尺寸和预想的不一样？

明确选择输出格式时，最终后缀会按格式调整。最终尺寸由目标图处理后的网格数量与输出 Tile 尺寸共同决定，参见“尺寸与格式”的例子；实际结果区提供最终路径和尺寸。

为什么使用记录没有数据？

使用统计在勾选“质量分析”的生成任务到达分析提交点后写入。普通生成不会提交这份统计，分析提前退出或统计提交失败时也不会产生本轮完整记录。

服务断线或提交超时后怎么办？

页面会保留最后状态并自动重连。若提示“提交结果未知”，先检查任务列表确认是否已经创建任务，再决定是否重新提交，以免重复执行。

为什么刷新后某些开关仍然勾选？

页面会恢复你上次的表单草稿，包括勾选状态。“默认关闭”表示新表单的初始设置；开始新任务前可以调整已恢复的选项。
